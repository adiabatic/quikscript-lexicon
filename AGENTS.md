# Quikscript Lexicon

- All repo prose — docs, docstrings, comments, test names, and user-visible Desk strings — uses American spellings ("spelled", "recognized", "color").
- British spellings stay where they are data or quotation: verbatim quotes from the Quikscript Manual or other sources, corpus headwords and lexicon entries (the ReadLex corpus is British English), rule slugs and IDs that name data, and license texts.
- Write repo prose literally. Say what the code does in plain words, and use no metaphor, flourish, or personified components: write "checked against" rather than "held to", "tests" rather than "proves", and "the validator fails when" rather than "the validator demands". Terms from the Quikscript Manual, ReadLex, Hunspell, and LSP are terminology, not metaphor, so keep them.
- Comments explain why: gotchas, workarounds, and Manual citations. Don't write comments that restate the code.
